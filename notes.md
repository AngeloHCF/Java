Main.class is the compiled bytecode (the file the computer runs)
Java uses a two step process to run code: compilation and execution

Main.java: plain text file containing the human readable Java code
Main.class binary file generated automatically when you compile your code JVM (Java Virtual Machine) reads it. JVM reads and translates it to machine code that the computer's CPU can execute
